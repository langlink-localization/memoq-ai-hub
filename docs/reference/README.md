# External SDK references

This public repository does not mirror memoQ SDK archives, documentation, sample source code, tools, or assemblies.

Use the official sources and review their terms before downloading or using them:

- [memoQ SDK downloads](https://docs.memoq.com/current/sdk-docs/)
- [memoQ End-User License Agreement](https://www.memoq.com/legal/end-user-license-agreement/)
- [memoQ APIs and SDKs overview](https://www.memoq.com/ecosystem/)

The build resolver downloads a pinned MT SDK archive from the official memoQ documentation site into the ignored `.memoq-sdk/` directory and extracts only the two compile-time reference assemblies required by the plugin. Those files are not part of this repository or its MIT license.
