# Post-v1.0.37 regression audit

Date: 2026-09-09 (Asia/Shanghai). Baseline: `v1.0.37`; reviewed release head: `9af028e` (`v1.0.43`). The range contains 21 commits affecting 106 files. Fixes are delivered in v1.0.44.

## Confirmed findings

| Finding | Origin | Repair |
| --- | --- | --- |
| Windows credential availability was frozen before Electron became ready, preventing later provider key saves. | Existing credential lifecycle defect, also present before v1.0.37. | Check availability on each operation; defer and retry legacy migration; retain OS encryption and sanitized failures. |
| Dashboard messages omitted preview bridge status and prepared update directories. | v1.0.38 runtime state-view extraction. | Restore the messages using the existing preview status snapshot and update state. |
| Dependabot alert 140: GHSA-2883-xcg3-v3hh in js-yaml. | Transitive development dependency. | Pin js-yaml 4.x to 4.3.2 and update the lockfile. The patch was published 2026-08-26, outside the ten-day maturity gate. |

The startup initialization and missing renderer binding defects reported for v1.0.38-v1.0.42 were already corrected in v1.0.43. This release retains those repairs and extends undefined-variable lint coverage outside the renderer.

## Coverage and evidence

- Compared extracted renderer controllers and their consumers against v1.0.37. Fifty-four extracted functions had identical normalized syntax trees; the remaining diagnostics helper used the equivalent injected state parameter. Checked controller returns, draft state, navigation, preview, and history bindings.
- Compared the old preload/main IPC registration with the extracted IPC surface using 200 normalized bridge-to-worker cases. All cases preserved forwarding behavior; reviewed local import, URL, and installer handlers separately.
- Compared extracted runtime history, asset, and state-view functions. Fourteen extracted functions were identical after removing comments and source locations. The state-view notice difference above was repaired.
- Reviewed 37 changed JavaScript files across typed asset, provider, QA, shared, preview, bilingual, and gateway code. Twenty-seven normalized syntax trees were unchanged; reviewed the remaining guards, aliases, and equivalent callback changes.
- Reviewed dependency, Vite entrypoint, CI, and release-script changes. The range did not change native plugin C# source. Existing release packaging remains the publication path.
- Credential regression tests exercise startup readiness transitions, later unavailability, native readiness exceptions, deferred legacy reads/listing, failed migration preservation, and retry. Dashboard tests exercise preview failure/connection and prepared/available/failed updates. Both new defect tests failed before their respective repairs.
- A Windows Electron smoke check created the service before `app.ready`, saved a synthetic value after readiness, quit normally, and recovered the encrypted value in a second process. No real provider key or provider network request was used.
