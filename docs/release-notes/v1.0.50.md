## User interface

- The desktop app now runs on Ant Design 6 and React 19, and its theme goes through the shared LangLink antd kit (`@langlink-tech/antd-kit` 0.10.1).
- Description, placeholder, link, and status text are raised to at least the WCAG 4.5:1 contrast floor. Seed colors and the existing layout are unchanged.
- The app follows the Windows high-contrast, reduced-transparency, and forced-colors settings.
- Components use the Ant Design 6 property names, so the console no longer shows deprecation warnings.

## Compatibility and delivery

- The memoQ plugin contract, the preview helper, and the database schema are unchanged. No settings migration is required.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
