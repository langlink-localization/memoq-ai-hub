## Architecture

- Preview-helper documents, parts, and segments now use shared domain types at the match, neighbor-context, and context-query boundary. Raw helper JSON is still cloned into that shape before matching.
- memoQ integration install options (`memoqVersion`, `customInstallDir`, `selectedInstallDir`) use the same shared install-options type from status lookup through installation.
- The local database and update service do not interpret runtime state, profiles, or preview parts, so their storage and download boundaries stay on their own types.
- The memoQ plugin contract and the database schema are unchanged.

## Compatibility and delivery

- No settings migration is required.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
