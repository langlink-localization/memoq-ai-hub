## Highlights

- The desktop app now runs strict type checking over its plain-JS sources: JSDoc annotations are verified with `tsc --noEmit` (TypeScript 7.0.2) through the new `pnpm run typecheck` script and a CI step. The typed surface covers the entire `src/shared` contract layer, the full QA and bilingual modules, the TM matcher, the gateway payload validator, and the renderer IPC surface table.
- Repository governance now pins the toolchain: the TypeScript version, the `typecheck` script, and the CI type-check step are all asserted by repo tests, so the gate cannot be quietly removed.
- Contributor rules were updated: modules under `apps/desktop/src/shared/` must keep the type check green, and the typed surface is expected to grow rather than shrink.

## Compatibility

- No IPC channel, HTTP route, database schema, plugin protocol, Provider, Profile, asset, QA, history, or update-manifest behavior changed. The database schema version stays at 1.
- The annotations are type-level only; the few touched statements are behavior-equivalent rewrites covered by existing QA, bilingual, logging, and gateway tests.
- No plugin-side change is required relative to v1.0.38.
