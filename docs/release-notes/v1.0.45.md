## Reliability and architecture

- Worker IPC replies remain bound to their originating process generation. Restart/shutdown rejects pending and new requests, and retired workers cannot restore readiness or dispatch main-process work.
- Concurrent credential reads share one in-flight IPC request, with independent retry and mutation invalidation.
- Translation and connection-test health updates share provider/configuration ownership. Old translations cannot overwrite a newer edit, credential rotation, or connection check; cache-only translations do not claim connectivity.

- Provider saves and connection tests preserve configuration written by other concurrent requests. Stale tests cannot restore deleted providers or overwrite a newer test result.
- Temporary Windows credential decryption failures can recover on retry; successful reads restore credential availability, and delayed reads cannot refill the cache after deletion.
- Dashboard history progress and the latest translation outcome remain accurate during lightweight polling and filtered history views. Polling reads only history count and latest-result metadata.
- Gateway logging is initialized per server, using the runtime's data paths; importing the server no longer creates user-data directories.

## UI and interaction

- Asset previews ignore obsolete responses after switching or closing, expose local retry, and prevent duplicate structure saves.
- Project-rule drafts warn before dismissal or navigation. Save and cancel remain in the drawer footer, and pending writes cannot be discarded.
- AI service operations reject duplicate submissions. Provider and profile fields are disabled during save, and save-and-leave cannot be interrupted by Escape.
- Page failures leave application navigation available and offer a local retry. Global refresh preserves applied history filters.
- Background polling pauses in hidden windows and never overlaps its own pending request, including Quality Checks and the Assistant.
- Keyboard users can skip to the main content, the language selector has an accessible name, and the interface honors system reduced-motion settings.

## Compatibility and delivery

- Local release candidate only. No release, tag, push, or pull request is created by this preparation.
- No database migration or memoQ plugin protocol change. Existing profiles, providers, and assets use the same formats.
- Validation and manual-runtime limits are recorded in the architecture and UI/UX audit.
