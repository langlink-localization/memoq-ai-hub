## What's Fixed

- Prevented failed AI QA requests from being presented as successful checks with no reportable issues.
- Preserved the resolved provider, model, elapsed time, repair attempt, and error code in QA execution summaries.
- Stopped retrying provider and transport failures as malformed QA output while retaining the single repair attempt for invalid JSON or schema responses.
- Prevented Translate from sending the existing target text back to the model, reducing target-copy anchoring while keeping the current target available to Polish.

## Usability

- QA failures, circuit-open states, and cancellations now use explicit warning states with a retry action.
- Assistant results identify the provider by name and distinguish provider-generated output from cached output.
- Internal model record identifiers are resolved to the configured model name in QA controls and diagnostics.

## Notes

- Existing profiles, provider configuration, QA storage, and memoQ plugin contracts remain compatible.
- Translate, Polish, and QA results remain copy-only and are never written back to memoQ.
