## What's New

- Added a Quality Check history tab with source, document, date, and automatic-preview filters, summary statistics, detailed findings, feedback state, deletion, and CSV/XLSX export.
- Added global prompt presets for QA, Translate, and Polish, including built-in presets, custom copies, editing, validation, restore, and deletion.
- Added preset and per-request instruction controls to the compact Assistant window and the Quality Checks page.
- Moved the Assistant launcher to the application header and promoted Quality Checks and Translation Records to independent top-level navigation items.

## What's Fixed

- Kept automatic Preview QA history while hiding it by default, and preserved current snapshot hash/revision checks so stale results are not shown.
- Unified terminology selection and prompt-version fingerprints across deterministic QA, AI QA, Translate, and Polish operations.
- Improved desktop worker supervision, startup error recovery, tray behavior, local gateway validation, secret handling, and packaged-resource checks.
- Hardened Windows ZIP and compact archive generation and verified the packaged application contents before publication.

## Usability

- QA history loads on demand and refreshes after checks without joining the Preview polling loop.
- Built-in prompt presets remain inspectable and editable, can be restored to defaults, and can be saved as independent copies.
- Translate, Polish, and QA retain explicit actions, cancellation, provider/model diagnostics, and copy-only output.

## Notes

- Existing profiles, provider configuration, QA storage, and memoQ plugin contracts remain compatible.
- Translate, Polish, and QA results remain copy-only and are never written back to memoQ.
