## What's New

- Removed bundled memoQ SDK binaries, AddinSigner, official SDK samples, and vendor-derived assets from the current repository and Windows release packages.
- Added a pinned SDK resolver that verifies the official archive and keeps the two required compile-time assemblies in an ignored local cache.
- Added repository checks that prevent restricted SDK files and known vendor assets from being committed again.
- Clarified the MIT license scope and the project's independent, unofficial status.

## Notes

- This release includes the dependency security updates shipped in v1.0.27.
- Existing profiles, provider connections, translation records, assets, memoQ integration contracts, gateway APIs, and storage formats remain compatible.
- Building from source requires Node.js 22.12.0 or newer; packaged Windows users do not need to install Node.js.
