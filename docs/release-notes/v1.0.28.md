## What's New

- Removed previously tracked memoQ MT, QA, and Preview SDK mirrors, SDK reference binaries, AddinSigner, and vendor sample assets from the current repository tree.
- Added a pinned memoQ MT SDK resolver that verifies the official archive SHA-256 and extracts only the two required compile-time assemblies into an ignored local cache.
- Prevented memoQ SDK reference assemblies from being copied into plugin or desktop release artifacts.
- Replaced the vendor sample-derived plugin icon with an original project asset and changed `ClientDevConfig.xml` to a generated build resource.
- Added repository checks that reject restricted memoQ/Kilgray binaries, SDK archives, sample trees, and known vendor asset hashes.
- Clarified that the MIT license applies only to material LangLink Localization owns or is authorized to license, and that this project is not affiliated with memoQ Ltd.

## Licensing and Release Notice

- This release does not contain memoQ/Kilgray SDK assemblies, AddinSigner, SDK archives, or copies of official SDK examples and documentation.
- The memoQ integration remains a component built against memoQ APIs. Publishing this release reflects the repository owner's internal risk decision and does not represent memoQ approval or remove obligations under memoQ's terms.
- Earlier public release binaries were withdrawn as part of this licensing cleanup. Git history was not rewritten in this release.

## Notes

- This release includes the dependency security updates shipped in v1.0.27.
- Existing profiles, provider connections, translation records, assets, memoQ integration contracts, gateway APIs, and storage formats remain compatible.
- Building from source requires Node.js 22.12.0 or newer; packaged Windows users do not need to install Node.js.

## Validation

- Repository license-boundary tests, desktop regression tests, plugin build and runtime regression tests, Windows packaging tests, and ZIP/7z content scans passed before release.
