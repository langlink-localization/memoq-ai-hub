## Deterministic memoQ terminology rules

- Imported memoQ term rules now control source matching and target terminology checks instead of remaining reference metadata only.
- Supports case-sensitive, case-insensitive and permissive capitalization, exact word matching, bounded HalfPrefix suffix matching, and language-specific NonTerm restrictions.
- Source and target rules follow their language when translating in the reverse direction. Ordinary multilingual assets stay reusable, while existing directional rules remain in force.
- Custom, Fuzzy, wildcard and unknown or conflicting rules are explicitly marked unsupported. Affected entries are excluded rather than silently matched with different semantics.

## Inspect and test rule behavior

- Expanded asset previews show raw memoQ rules, effective behavior, applied defaults and unsupported tokens by language.
- Test assets accepts optional target text for local terminology validation without calling an AI provider.
- Translation evidence shows the actual matched source text, source and target rules, and target check outcome. Unsupported-rule warnings remain visible even when no term matches.
- Required and forbidden constraints sharing a source span are retained, and legacy case-sensitive source matching is corrected.

## Compatibility and delivery

- Existing files and history are preserved. Updated matcher fingerprints prevent reuse of exact translation cache entries generated under older rule semantics.
- HalfPrefix is deterministic suffix matching, not stemming or memoQ's proprietary fuzzy engine; see the glossary compatibility guide for supported behavior.
- The memoQ plugin contract and database schema are unchanged; no settings migration is required.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
