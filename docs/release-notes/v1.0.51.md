## 术语识别与导入

- 同一份多语言术语表可配置多个语言栏位，按翻译任务的语言对匹配，支持反向翻译，无需重复上传。
- 通过语言名称搜索选择栏位语言，并展示样例内容；支持无表头文件，保留第一行术语。
- 修复简繁体和明确地区语言之间的术语串用；空单元格不跨行配对，多语言展开超过 50,000 个条目时明确报错。
- 多语言预览交错展示不同语言对的样例，支持正确读取带引号、逗号和换行的表格内容。

## 资产管理

- 提供直接的术语表与翻译记忆导入入口，文件选择器按类型过滤。
- 资产列表显示已配置语言，支持按文件、语言、翻译配置搜索以及绑定状态筛选。
- 可直接重命名资产、绑定或解绑翻译配置；保存前列出同类资产替换内容，并防止覆盖并发修改。
- 相应功能关闭时提供显式启用选项；未保存修改受到保护。
- 被引用的资产需先解绑才能删除。删除只移除应用内的导入副本，保留原始源文件。
- 保留最新 main 的共享 AntD kit、Listy 和响应式组件组合。
