## What's Changed

- Split the desktop runtime composition root into focused services for translation, QA, history, assets, profiles, providers, prompt presets, aggregation, and Preview context resolution.
- Split renderer state and presentation helpers out of the main application shell so provider, profile, asset, log, history, and time-formatting behavior can evolve independently.
- Split provider transport support from the provider registry and separated the memoQ session bridge into dedicated gateway, mapping, and logging components.

## Reliability

- Added focused regression coverage for each extracted runtime, renderer, provider, and native boundary while retaining the existing public routes, payload shapes, storage formats, and UI behavior.
- Kept the memoQ SDK adapter and forwarding layer thin; provider and product behavior remains owned by the desktop application.
- Updated Vite main-process inputs so the new runtime modules are included in packaged builds.
