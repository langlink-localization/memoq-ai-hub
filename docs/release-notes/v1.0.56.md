## Reliable terminology language mapping

- Automatically detected regional language names, including memoQ headers such as `Portuguese_Brazil`, now resolve to valid language codes such as `pt-BR` and can be saved without manual corrections.
- Existing detected mappings and preview rows use the same normalized language codes. Invalid or duplicate language selections identify the affected columns before saving.

## Clearer asset previews

- Glossary previews show actual notes separately from entry and term metadata. IDs, categories, timestamps, and repeated source/target metadata no longer clutter the Note column.
- Expand a row to inspect labelled metadata, scope, and parsed rules, with copyable values. Long text wraps, literal business tags remain visible, and empty details stay collapsed.
- Multilingual concept previews retain notes and extra file columns. Column positions distinguish repeated headers, and available language-specific metadata stays grouped by language.
- Custom TM previews expose parsed metadata and context, with translated column headings and readable boolean values in glossary previews.
- Metadata is identified as reference information; its presence does not imply that an imported matching rule is supported or active. Use Test assets to verify actual matches.

## Compatibility and delivery

- Preview cleanup does not rewrite imported files, stored history, or terminology prompt metadata. Existing directional rule behavior is preserved.
- The memoQ plugin contract and database schema are unchanged; no settings migration is required.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
