## What's Changed

- Unified QA finding review across Quality Check, Preview Assistant, and QA history with severity, category, source, and review-state filters.
- Added evidence and suggestion details, copy actions, persistent feedback, immediate review-state updates, and responsive bilingual keyboard-accessible controls.
- Made rule disabling effective: eligible findings now disable the latest matching Profile rule before recording `rule-disabled` feedback, with idempotent and partial-failure handling.

## Reliability

- Added bounded desktop worker request lifecycles: 30 seconds for ordinary operations, 135 seconds for Provider, single-segment QA, and Assistant work, and 10 minutes for document, asset, export, integration, and update operations.
- Worker timeouts now return `DESKTOP_WORKER_REQUEST_TIMEOUT` with status 504, release all pending state, ignore late responses, and do not restart a healthy worker.
- Provider secrets now fail closed when Windows secure credential storage is unavailable. Legacy Base64 values are migrated only after OS encryption succeeds and verifies, and successful migration removes known reversible backups.
- Fixed the production runtime composition so Provider secrets use the main-process secure bridge rather than the legacy local fallback.

## Quality gates

- Added focused coverage for QA review filtering, persisted feedback, shared finding actions, and Profile rule disabling.
- Replaced two obsolete skipped Provider prompt tests with assertions against the current structured OpenAI request contract.
- Added ESLint flat configuration for desktop source and tests, tooling scripts, and repository tests, including recommended correctness and React Hooks rules.
- Added `pnpm run lint` to the main CI workflow.

## Compatibility

- memoQ, HTTP, Provider, and persisted product data contracts are unchanged.
- memoQ 12 live-host validation remains pending. This release does not claim that Confidence or Info display has been verified in a real memoQ host.

## Rollback

- Roll back to `v1.0.32` if desktop startup, Provider secret saving, long-running QA/assets, or update downloads regress.
- A rollback may temporarily restore the previous reversible secret fallback; do not use that fallback as a workaround for unavailable Windows secure storage.
