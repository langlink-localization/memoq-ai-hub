## What's New

- Unified the desktop shell, page headers, editor actions, forms, feedback, empty states, and responsive behavior under the Ant Design governance contract.
- Added guarded pending states and consequence-aware confirmations for refresh, import, export, delete, integration, update, and unsaved-edit workflows.
- Improved English and Chinese localization, keyboard accessibility, table overflow handling, compact navigation, and the 768 px drawer experience.
- Split Dashboard and Translation Records into lazy-loaded page modules and isolated dashboard polling so unchanged status updates no longer rerender unrelated page trees.
- Removed unreachable legacy configuration surfaces and consolidated shared presets, hover text, table widths, and duplicated presentation logic.
- Hardened Electron development and packaged-runtime module, desktop-contract, and SQL WASM resolution discovered during real multi-width UI verification.

## Notes

- Existing profiles, provider connections, translation records, assets, memoQ integration contracts, gateway APIs, and storage formats remain compatible.
- Supported navigation remains expanded at 1200 px and above, compact from 769-1199 px, and drawer-based at 768 px and below.
- The release passed desktop, repository, production renderer build, and real Electron viewport checks before tagging.
