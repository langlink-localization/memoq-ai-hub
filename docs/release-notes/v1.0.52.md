## Security and dependencies

- Six Dependabot alerts are resolved by updating shell-quote, proxy-addr, and source-map-js, and removing braces, sprintf-js, and http-cache-semantics from the dependency tree.
- The Windows build uses Electron Forge 8.0.1 and Electron Packager 20.3.0. Main and preload bundles use the new CommonJS entry format, while worker and runtime module paths remain compatible.
- Runtime dependency collection includes CommonJS bundles, and packaging avoids copying duplicate source entry files.

## Compatibility and delivery

- The memoQ plugin contract and the database schema are unchanged. No settings migration is required.
- Node.js 22.13 or newer is required only for source builds. Installed desktop users do not need to install Node.js.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
