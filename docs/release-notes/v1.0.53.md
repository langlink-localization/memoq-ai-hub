## Terminology reliability

- CJK terms next to numbers and Latin level markers now match without weakening boundaries inside identifiers.
- Disabled glossaries no longer contribute terms or metadata. Cached translations are checked against applicable terminology, and noncompliant results are not cached.
- Profiles can reject terminology violations and optionally allow one additional repair attempt per failing segment. Repairs preserve tags and placeholders; policy rejections do not trigger plugin formatting retries.

## Translation records and asset testing

- Records show source and target text first, with matched terms, asset fingerprints, model details, cache provenance, and terminology status for each segment. Older records explicitly show when evidence was not recorded.
- Test saved profile assets locally using language names and sample source text, without making a model call.
- Translate a recorded segment again with a current profile, bypass caches, and compare the new result with the original. The original record and memoQ translation are preserved.
- Plugin result information includes a Hub record ID. Paste it into the plugin Options window to open the exact record in Hub, including results from aggregated requests and retries.

## Compatibility and delivery

- Existing profiles retain advisory terminology behavior. Strict rejection and paid repair attempts are opt-in.
- History evidence and response fields are additive. No database schema migration is required; older records are not reconstructed from current assets.
- Start the updated Hub once on Windows to register record navigation. Portable users should restart Hub after moving its folder.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
