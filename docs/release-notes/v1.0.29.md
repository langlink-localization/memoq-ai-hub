## What's New

- Added optional memoQ MT confidence and concise deterministic information while preserving compatibility with older desktop and plugin combinations.
- Added Quality Checks for the active Preview segment with local deterministic checks, optional AI review, evidence-based findings, and locally stored feedback.
- Added read-only MQXLIFF, XLF, and XLIFF batch inspection with matching HTML, CSV, and JSON reports.
- Added an always-on-top compact quality window with pause, multi-display position recovery, and shared local results.

## Reliability and Privacy

- Real-time AI remains disabled by default; document summaries and full text require separate opt-ins.
- Revisioned Preview snapshots, cancellation, stale-response rejection, provider backoff, and circuit breaking prevent outdated AI results from replacing current findings.
- QA results and feedback are retained locally for 30 days, and version one only copies suggestions instead of writing changes back to memoQ.
- Added a fail-closed official Ant Design audit for complete, warning-free renderer scans.

## Notes

- Existing profiles, provider connections, translation records, gateway translation routes, and `StoreTranslation` behavior remain compatible.
- Deterministic checks and bilingual-file import remain available when Preview mapping or an AI provider is unavailable.
- memoQ 12 is the first live-host validation target; Confidence and Info visibility depends on host behavior.
