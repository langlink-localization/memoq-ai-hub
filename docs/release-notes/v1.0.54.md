## System proxy support

- Update checks and package downloads now follow the operating system's proxy settings, including PAC rules, through Electron's native networking stack.
- Proxy settings are refreshed before each request. No proxy port needs to be entered in AI Hub, and translation provider networking is unchanged.
- Proxy authentication failures provide a browser download fallback without storing proxy credentials.

## Update experience

- Downloads show progress and transfer speed, with controls to cancel or retry a failed download.
- The browser download button remains available for installed and portable builds, including during downloads and after errors.
- Stalled transfers time out and partial files are removed after cancellation or failure. Repeated clicks no longer start duplicate downloads.
- Retries download the complete package again; resumable and incremental downloads are not included.

## Compatibility and delivery

- HTTPS redirect validation and SHA-256 verification remain required before installation. The memoQ plugin contract and database schema are unchanged; no settings migration is required.
- System proxy behavior was verified with Electron on macOS. Windows packaging and automated checks run in CI; individual Windows proxy applications still require real-machine verification.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
