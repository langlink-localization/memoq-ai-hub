## Architecture

- The desktop runtime composition root now only wires services and keeps the public method names. Preview-bridge ingestion, one-shot translation-cache bypass, store-translations writeback, history spreadsheet export, and bilingual import QA each have their own owner.
- Provider-hub secret flags and 24-hour metrics are projected by the app-state read model.
- Strict JavaScript type checking now covers the runtime composition root, its services, the local database, memoQ integration, the preview helper client, and the update service.
- Shared runtime domain types name state, profile, provider, asset, and persistence shapes used at those boundaries. The memoQ plugin contract, gateway routes, and database schema are unchanged.

## Compatibility and delivery

- No settings migration and no memoQ plugin protocol change are required.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
