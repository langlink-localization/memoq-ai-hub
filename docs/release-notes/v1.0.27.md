## What's New

- Updated Electron and the desktop build toolchain to supported security-maintained versions.
- Updated SheetJS to the official 0.20.3 distribution and preserved existing XLSX import and export behavior.
- Removed vulnerable transitive dependency versions identified by GitHub Dependabot and added repository checks to prevent their return.

## Notes

- Existing profiles, provider connections, translation records, assets, memoQ integration contracts, gateway APIs, and storage formats remain compatible.
- This release requires Node.js 22.12.0 or newer when building from source; packaged Windows users do not need to install Node.js.
- The Windows release package, compact archive, update manifest, and packaged runtime were rebuilt and verified after the dependency upgrade.
