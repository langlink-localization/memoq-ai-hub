## Architecture

- The update manifest, downloadable asset, and persisted update-state shapes now have shared types. Manifest normalization, asset digest checks, and the saved update-state file use those shapes.
- The desktop database types the sql.js static API and the wrapper handle used by persistence: prepare, exec, export, and close. Query rows stay records keyed by column name.
- Preparing a portable update fails closed when the manifest asset is missing, instead of reading a name from an empty asset.
- The memoQ plugin contract and the database schema are unchanged.

## Compatibility and delivery

- No settings migration is required.
- Windows portable ZIP, compact 7z, Squirrel setup EXE, and the stable update manifest are published by the repository release workflow.
