## What's New

- Upgraded the compact Preview window into a two-mode Assistant with explicit Translate, Polish, and QA actions.
- Added profile-level QA prompt templates, request-only QA instructions, and temporary terminology resource overrides.
- Added deterministic and AI execution summaries so completed checks, cache hits, provider failures, and confidence-filtered findings are distinguishable.

## Reliability and Usability

- Fixed oversized Quality Checks switches while preserving accessible 40 px label targets, keyboard focus, immediate saving, and rollback on failure.
- Prevented stale Preview results from appearing after the active segment or document changes.
- Added clear zero-finding, AI-disabled, AI-failed, retry, cancellation, provider/model, elapsed-time, and terminology-use states.

## Notes

- Existing profiles remain compatible; QA templates use defaults until customized and saved.
- Real-time background AI remains disabled by default. A user-initiated QA check is an explicit request.
- Generated translations, polished text, and QA suggestions are copy-only and are never written back to memoQ.
- The memoQ plugin MT contract, `StoreTranslation` behavior, and existing `/mt/translate` route remain unchanged.
